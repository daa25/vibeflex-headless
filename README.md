# VibeFlex Headless Commerce

A headless commerce project focused on product discovery, storefront experience, catalog operations, and scalable integration patterns.

The project separates the customer-facing experience from the underlying commerce and data services so the storefront can evolve independently while keeping operational systems connected behind it.

## What the project demonstrates

- Customer-facing product and catalog experience
- Search, navigation, and cart-oriented storefront workflows
- Commerce API integration patterns
- Server-side application services with Express
- Type-safe application architecture
- Database access with Drizzle ORM
- Automated testing with Vitest
- Responsive component-driven UI
- Operational documentation and catalog-audit workflows

## Technology

- React 19
- TypeScript
- Vite
- Express
- Drizzle ORM
- TanStack Query
- tRPC
- Zod
- Tailwind CSS
- Radix UI
- Vitest

## Operations perspective

This repository is less about creating another storefront theme and more about treating ecommerce as an operating system: product data, customer experience, catalog maintenance, integrations, and conversion flows all need to work together reliably.

## Portfolio focus

Presented as a **commerce-operations and digital-experience case study** demonstrating how business requirements can be translated into a maintainable technical system.
